    3 · 컴포넌트 규칙

    머티리얼 기본값이 새어나오는 지점을 테마로 전부 덮기.
    • radius 0 · 테두리 ink 2.5px — 예외 없음
    • 그림자 3단: 기본 4px / 강조 7px / 버튼 0 5px 0 ink
    • 프레스 = 4px 내려앉고 그림자 제거, 리플 제거(NoSplash)
    • 테마로 덮을 것: textButton · outlinedButton · segmentedButton · dialog · datePicker · popupMenu · dropdownMenu
    • 선택 강조색은 teal 단일 — 카테고리 색은 아이콘에만
    • SnackBar 남용 → 인라인 힌트 박스로 이동
    • 마이너스 기호 U+2212 (−)로 통일
    • SystemUiOverlayStyle.dark 지정 (상태바 아이콘)
    • 스크린리더 라벨 한국어 → 스페인어 (cat_sprite.dart)
