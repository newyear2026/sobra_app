# 캐릭터·장면 모션 제작 및 사용 가이드

## 범위와 제작 원칙

온보딩에는 무료 선택 캐릭터인 Michi와 Poodle만 등장한다. Schnauzer는 컬렉션에서 보상형 광고 2편을 보면 영구히 얻는 캐릭터다.
총 8종은 **캐릭터 동작 6종 + 공통 장면 연출 2종**이며, 캐릭터마다 이미지 8개를 만드는 의미가 아니다.

| 모션 | 역할 | 온보딩 두 캐릭터 | 이후 출시 캐릭터 |
| --- | --- | --- | --- |
| 대기 | idle | 필수 | 필수 |
| 걷기 | activity | 필수 | 이동 사용처가 있을 때 선택 |
| 계산 | processing | 필수 | 기본 제작 |
| 저축·긍정 반응 | positive | 필수 | 기본 제작 |
| 축하 | success | 필수 | 필수 |
| 걱정·주의 | warning | 필수 | 필수 |
| 등장 후 자리 잡기 | 공통 장면 연출 | 온보딩 적용 | 별도 제작 불필요 |
| 빗줄기 | 공통 배경 연출 | 온보딩 적용 | 별도 제작 불필요 |

추가 출시 캐릭터의 기본 제작량은 5종이다. 비 맞은 효과 등 온보딩 전용 표현은 초기 두 캐릭터에 적용한다.
걱정은 예산 초과에도 필요하므로 온보딩 전용이 아니다. 계산은 향후 공통 숫자 안내를 위해 기본 제작하되,
실제로 사용하지 않는 화면에 억지로 배치하지 않는다.

## 화면별 사용 기준

| 화면·상황 | 모션 | 재생 정책 |
| --- | --- | --- |
| 온보딩 도입 | 빗줄기 | 반복, 맑은 방에서는 종료 |
| 첫 만남 | 등장 + 걷기 → 걱정 | 도착 후 걱정 1회, 자세 유지 |
| 캐릭터 선택 | 대기 | 느린 반복 |
| 급여 주기 설정 | 계산 | 입력 대기 중 휴지 구간 권장 |
| 날짜 설정 | 없음 | 입력에 집중 |
| 예산 설정 | 저축 | 입력 대기 중 휴지 구간 권장 |
| 온보딩 완료 | 등장 + 걷기 → 축하 | 축하 1회 후 안정 자세 유지 |
| 홈 기본 상태 | 대기 | 느린 반복 |
| 홈 예산 초과 | 걱정 | 1회 후 유지 |
| 예산 화면 | 저축 | 동작 사이 휴지 구간 권장 |
| 기록 저장 성공 | 축하 | 실제 저장 성공 후 1회 |
| 미션·보상 완료 | 축하 | 실제 완료 이벤트에 1회 |
| 컬렉션·설정 | 대기 대표 자세 | 정적 표시 기본, 선택 미리보기는 반복 가능 |

## 현재 Michi 재생 설정

| 동작 | 프레임 | 1회 길이 | 현재 기본 재생 |
| --- | --- | --- | --- |
| 대기 | 8 | 2.8초 | 반복 |
| 걷기 | 12 | 1.8초 | 반복 |
| 계산 | 12 | 3.6초 | 반복 |
| 저축 | 12 | 4초 | 반복 |
| 축하 | 12 | 2.2초 | 1회 후 마지막 자세 유지 |
| 걱정 | 8 | 1.6초 | 1회 후 마지막 자세 유지 |

등장 전체 시간은 첫 만남 2.2초, 완료 장면 2.4초이다. 이동은 전체의 72% 시점에 끝난다.
빗줄기는 0.72초 주기의 코드 기반 효과이다. 위 속도는 신규 캐릭터의 검수 시작값이며 프레임 수는 FPS가 아니다.

## 에셋·품질 계약

- 프레임 320×360px, 가로형 RGBA 투명 PNG, 최근접 보간.
- 8프레임 시트 2560×360px, 12프레임 시트 3840×360px.
- 파일명 `{role}-{frameCount}.png`, 폴더 `assets/characters/{id}/`.
- 중심 x=160, 바닥선 y=344, 안전 여백 16px. 캐릭터 비율·팔레트 유지.
- 접지 동작은 발이 뜨지 않아야 한다. 점프만 의도된 높이 변화를 허용한다.
- 소품이 이유 없이 사라지거나 이동하지 않아야 한다. 마지막→첫 프레임 연결까지 검수한다.
- 읽기·입력 중에는 준비·마무리 자세에 머무는 시간을 확보한다.
- 완료 동작은 1회 후 안정 자세 유지. 대기 루프 전환은 별도 명시한다.
- 동작 줄이기에서는 대표 정지 자세를 표시하고 등장 이동·빗줄기를 멈춘다.
- 대표 프레임과 위치 보정은 캐릭터별로 관리한다. Michi 값을 다른 캐릭터에 복사하지 않는다.

프레임 번호는 0부터 시작하고 `playRange`는 양 끝을 포함한다. `posterFrame`은 정지 표시,
`holdFrame`은 완료 후 유지 자세다. `holdFrame` 생략 시 재생 구간 마지막 프레임을 유지한다.
신규 1회 재생 시트는 마지막 프레임 자체를 안정 자세로 제작한다.

## 현재 구현과 출시 전 남은 작업

Michi와 Poodle만 온보딩 선택 화면에 등록되어 있다. Schnauzer는 컬렉션에서 광고 보상으로 얻는 캐릭터다. 광고로 얻은 사용자가 있으므로 나중에 구매로 바꾸지 않는다.
세 캐릭터 모두 각각 여섯 역할의 시트를 제공한다. 역할이 누락되면 현재 렌더러는 오류를 발생시키므로
향후 다섯 종 팩을 등록하기 전 누락 역할의 대체 표시를 구현해야 한다.
계산·저축 반복 사이 휴지 시간과 화면별 재생 정책도 계속 검수한다.

현재 12프레임 Michi는 코드의 세로 보정으로 바닥선을 맞추며, 원본 시트 자체가 정렬된 것은 아니다.
저축 소품 연결 등 원화 연속성은 추가 검수 대상이다.
`docs/motion-previews/*.gif`는 속도·위치 보정 이전 자료이므로 최신 동작 승인 자료로 사용하지 않는다.

## 관리 위치

- 정책: 이 문서
- 팩 메타데이터: `assets/characters/{id}/character.yaml`
- 실제 재생 설정: `lib/widgets/cat_sprite.dart`
- 장면 연출: `lib/widgets/prologue_scene.dart`
- Schnauzer 원화와 자세: `design/characters/schnauzer/`
- Schnauzer 프레임별 원본: `design/characters/schnauzer/generated-v2/`
- Schnauzer 8·12프레임 시트 정렬 및 미리보기 생성: `tool/build_schnauzer_motion.py`

현재 앱은 YAML을 런타임에 읽지 않는다. Dart와 YAML, 이 문서의 현재 설정 표를 함께 갱신한다.
YAML의 `frameOffsetsY`는 Dart의 `frameOffsets`에 대응하는 원본 픽셀 단위 세로 보정이다.
신규 팩은 앱 카탈로그와 pubspec.yaml에 등록한다.
기존 8프레임 정규화 도구는 혼합 프레임 팩에 적용하기 전 지원 범위를 확인해야 한다.
