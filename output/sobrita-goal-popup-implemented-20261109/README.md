# 목표 팝업 — 실제 Flutter 구현 화면

2026-11-09. 이 폴더의 PNG는 이미지 생성 시안이 아니라 실제 앱 위젯을 렌더링한 화면입니다. 사용자 데이터 대신 격리된 SharedPreferences 테스트 데이터를 사용했습니다.

- `active-ko.png`: 남은 생활비 20,000원 → 기존 1억 목표에 전액/일부 반영.
- `empty-ko.png`: 목표 없음 → 목표 생성 → 같은 주기의 금액 재확인.
- `completed-ko.png`: 1억 목표 달성 → 완료 팝업, 홈의 100% 카드, 선택적인 새 목표 생성.
- `before-layout-adjustment/`: 최초 검토 화면. 팝업이 캐릭터 얼굴을 가려 위로 옮기기 전의 증거입니다.
- `gallery.html`: 실제 구현 세 상태.
- `comparison.html`: 승인 시안과 실제 구현을 함께 보는 비교 자료.

논리 화면 390×844, PNG 780×1688(@2x), 실제 PixelifySans·SobraHangul 폰트와 기존 방/캐릭터 에셋입니다. 주간 예산 100,000원, 지출 80,000원, 11월 2~8일 마감, 11월 9일 현재 시각의 예시입니다. 홈의 다음 주기 금액은 이 데이터에서 계산되므로 이전 시안의 배경 예시 금액과 다릅니다. 실제 사용자 통화나 잔액은 변경하지 않았습니다.

재현:

```sh
flutter test --no-pub --dart-define=CAPTURE_GOAL_DIALOG_UI=true test/savings_goal_dialog_test.dart
```

동작 검증:

- 주기 배정 저장·중복 방지·재시작·복원·저장 실패·지출 수정·완료 목표 보관: 신규 도메인 테스트 11개.
- 팝업 흐름·전액/부분·범위·취소·설정 후 확인·완료 한 번·320×640/1.3배 글씨: 14개.
- 완료 카드·새 목표 취소·보관 이력: 4개.
- 실제 AppShell 자동 팝업·재시작 한 번·다른 알림 순서: 6개.
- 실제 위젯 화면 캡처와 팝업 전후 정사각형 방 크기/위치 보존: 3개.

마감 내역에서도 다시 배정하거나 현재 목표의 배정액을 바꿀 수 있습니다. 배정은 수입·현금·생활비·XP를 변경하거나 은행 이체를 실행하지 않습니다. 이 캡처는 네이티브 기기에 설치한 실행 결과가 아닌 Flutter 위젯 렌더입니다.
