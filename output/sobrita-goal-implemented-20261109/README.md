# 목표 카드 — 실제 Flutter 화면

현재 앱의 `SobraApp`, `HomeScreen`, `SavingsGoalCard`, `SavingsGoalScreen`을 Flutter 위젯 테스트에서 렌더링한 이미지입니다. 이미지 생성 도구로 만든 시안이 아닙니다. 에뮬레이터에 설치된 앱의 화면 캡처는 아니며, 테스트용 로컬 데이터로 렌더링했습니다.

- `01-home-empty-ko.png`: 목표가 없는 초기 상태. 기존 방 아래에 작은 안내와 ‘목표 만들기’가 표시됩니다.
- `02-home-active-ko.png`: 목표를 만든 상태. 예시 목표 ‘새 운동화’, 목표 1,499 MXN, 시작 금액 300 MXN입니다. 상품 사진을 등록하지 않은 수동 목표라 기본 깃발 아이콘이 표시됩니다.
- `03-goal-link-entry-ko.png`: ‘목표 만들기’를 눌러 연 링크 입력 화면. 직접 입력으로도 이어집니다.

화면 크기 390×844 논리 픽셀, 2배 PNG 780×1688. 한국어·실제 Pixelify/SobraHangul 폰트, 기존 Michi·Casa clara 리소스를 사용했습니다. 날짜는 2026-11-09 오전 10시로 고정했고, 알림과 보상 팝업은 테스트 준비 과정에서 처리했습니다. 잔액 등 금액은 예시입니다.

## 재생성

```sh
flutter test --no-pub --dart-define=CAPTURE_GOAL_UI=true test/savings_goal_screen_test.dart --plain-name 'home keeps its room and five tabs when the goal changes'
```

일반 실행에서는 파일을 쓰지 않습니다. 별도 캡처 플래그가 켜진 경우에만 이 폴더에 저장하며, 기존 골든 이미지는 변경하지 않습니다.

## 확인한 동작

9개 위젯 테스트 통과: 초기 안내에서 수동 목표 만들기, 잘못된 금액 거부, 가져온 데이터의 저장 전 확인과 금액 수정, 링크 변경 시 이전 상품 가격 제거, 통화 불일치 시 금액 직접 입력, 삭제 확인·초기 상태 복귀, 320dp·1.6배 글자 크기의 영어와 한국어 화면, 목표 추가 전후 동일한 캐릭터 방 위치·정사각형 크기 및 기존 하단 메뉴 유지.

추가 검증: 목표 모델·영속성 테스트 10개, 상품 정보 파서·브라우저 대체 화면 테스트 12개, 공개 DOM 추출 JavaScript fixture 6개를 확인했습니다. 기존 백업·저장 안전성·예산·온보딩·기록 화면 회귀 테스트도 통과했습니다. 새 Flutter WebView 화면으로 쇼핑몰 실접속은 이번 구현에서 재검증하지 않았으며, 기존 독립 Android 테스트와 구분합니다.

변경 전 홈 기준 이미지 `home-before-es.png`와 갱신된 홈 골든은 모두 426×919입니다. 픽셀 비교에서 변경 범위는 `(20, 720)–(406, 847)`로, 상단부터 방 끝까지 및 하단 메뉴는 동일했습니다. 새 목표 카드와 그 아래 콘텐츠만 바뀌었습니다.
