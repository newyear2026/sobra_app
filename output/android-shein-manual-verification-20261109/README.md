# SHEIN — 사용자가 보안 확인을 완료한 뒤의 Android 테스트

결과: **부분 검증**. 상품명과 실제 상품 사진을 읽었고, 페이지에 포함된 상품 가격정보는 MXN 463.56으로 일치했습니다. 보안 확인 완료 뒤 화면에 표시되는 현재 판매가격은 확인하지 못했습니다.

| 항목 | 확인 결과 |
|---|---|
| 상품 | Women Long Dresses · 회색 원피스 |
| 실제 상품 사진 | 750×999 로드 완료, 상품 갤러리·메타·구조화 상품정보의 동일 이미지 |
| 페이지 내 상품 가격정보 | MXN 463.56 · 메타와 같은 상품의 4개 사이즈 데이터가 일치 |
| 화면에 표시되는 현재 판매가격 | 미확정 · 완료 후 두 관찰 모두 판매가격 요소에서 금액을 읽지 못함 |
| 보안 확인 | 사용자가 직접 완료했다고 응답, 완료 후 캡처에서 보안 창이 사라진 것을 확인 |
| 세션 | 같은 WebView 유지 · 검사 시 페이지 재로드/쿠키 삭제 없음 |

Android 16 / WebView 156.0.8078.47 / Pixel_3 에뮬레이터에서 한 상품을 검사했습니다. 공식 상품 API 연결이나 API 키는 사용하지 않았고, 보안 확인을 자동 조작하지 않았습니다. 사용자 조작을 기다린 뒤 읽기 전용으로 공개 상품 DOM을 두 번 확인했습니다.

사진과 가격정보는 목표 등록 화면에 미리 채울 후보로 쓸 수 있지만, **463.56을 검증된 현재 판매가격이나 최종 결제금액으로 자동 확정하면 안 됩니다.** 금액 확인·수정 단계가 필요합니다. 사이즈 선택, 배송비, 쿠폰, 결제는 검증하지 않았습니다.

이전 실패 기록은 다른 에뮬레이터의 WebView134 환경입니다. 따라서 이번 결과로 보안 확인만 완료하면 모든 환경에서 해결된다고 단정할 수 없습니다. 일부 상품 데이터는 보안 창이 떠 있을 때에도 이미 페이지에 포함되어 있었으므로, 보안 확인 자체가 데이터 접근을 새로 허용했다는 인과관계도 검증한 것은 아닙니다.

초기 DOM 판별기는 상품 위에 뜬 보안 창을 감지하지 못했습니다. 그 값만으로 통과를 판정하지 않았으며 실제 화면과 사용자 완료 응답을 근거로 전후 상태를 확인했습니다. 원본 JSON은 수정하지 않았습니다.

Sobrita 본 앱에는 적용하지 않았습니다. 수동 확인 테스트 앱의 현재 페이지·세션은 유지했습니다.
