# 목표 기능 — 빠진 부분 시안 (2026-11-09)

2026-11-09 코드 리뷰에서 찾은 빠진 부분 세 가지를 그린 제안 시안입니다. 배경은 격리된 테스트 데이터로 렌더링한 실제 앱 화면이고, 주황색 `NEW` 표시가 붙은 부분이 새로 제안하는 내용입니다. 아직 앱 코드에는 들어가지 않았습니다.

예시 목표는 **링크로 만든 상품 목표**입니다. 저장 데이터는 링크 가져오기가 만드는 그대로입니다(종류 `product`, Mercado Libre 상품 링크·이미지 링크·쇼핑몰 이름). 테스트에서는 쇼핑몰 사진을 받아올 수 없어서, 앱 안의 TV 그림을 상품 사진 대신 썼습니다. 홈 카드는 실제 카드와 같은 배치로 다시 그려 그 위에 얹었습니다.

예시 데이터: MXN 주간 예산 $3,000, 11월 2~8일 주기에 $1,200 남음, 목표 "스마트 TV 55" 4K" $8,999(링크에서 가져온 정가), 목표일 11월 13일, 현재 날짜 11월 9일.

- `01-home-deadline-ko.png`: 홈 목표 카드에 목표일 줄(`D-4 · 11월 13일까지 $1,299 더`)을 추가한 시안. **2026-11-09 구현됨.** 실제 화면은 `current-01-home-ko.png`, 코드는 `lib/widgets/savings_goal_card.dart`입니다.
- `02-bought-it-ko.png`: "목표로 샀어요" 기록 시안.
  - 저장된 상품 링크로 오늘 가격을 다시 읽어 산 금액에 채웁니다. 지금은 가져온 가격을 자동 갱신하지 않아서, 부엔핀 할인가($7,499)가 목표 정가($8,999)와 달라집니다.
  - 모아 둔 돈으로 산 지출이라 오늘 남은 돈과 이번 주기 예산은 바뀌지 않습니다.
  - 남는 돈은 다음 목표로 넘길 수 있습니다.
  - 지금은 이 경로가 없어서 일반 지출로 기록하면 주기 예산이 줄어듭니다.
- `03-cycle-close-xp-ko.png`: 주기 마감 팝업에 XP 줄과 "마감 결과 자세히 보기" 링크를 더한 시안. XP 125는 테스트 데이터로 실제 계산된 값입니다. 지금은 남은 돈이 있는 주기에서 정산 화면과 XP 합계가 보이지 않습니다.

## 홈 카드 날짜 줄 규칙 (구현됨)

`current-card-date-variants-ko.png`는 실제 코드로 렌더링한 카드입니다. 위에서부터 가까운 날짜, 내년 날짜, 날짜 없음입니다.

| 경우 | 카드에 보이는 줄 |
| --- | --- |
| 날짜까지 31일 이내 | `D-4` · `11월 13일까지 $1,299 더` |
| 31일보다 멀 때 | `2027년 11월 13일까지 주기마다 $25` (남은 돈 ÷ 오늘부터 그날까지의 월급 주기 수, 정수 단위로 올림) |
| 날짜 없음 | `$1,299 더 모으면 돼요` |
| 날짜가 지남 | `11월 13일 지났어요 · $1,299 더` |
| 달성함 | 줄 없음 |

연도는 올해가 아닐 때만 붙습니다. 주기 수는 현재 월급 일정으로 세고, 최대 600주기까지만 셉니다.

## 지금 구현된 화면 (비교용)

시안용 위젯 없이 지금 코드 그대로 같은 링크 목표를 렌더링했습니다. 쇼핑몰 사진만 테스트용 가짜 이미지 서버로 TV 그림을 내려줬습니다.

- `current-01-home-ko.png`: 홈 목표 카드. 상품 사진, 이름, 진행액, 퍼센트가 나오고 목표일은 나오지 않습니다.
- `current-02-goal-editor-ko.png`: 카드를 눌러 여는 목표 수정 화면.
  - 위에서부터 상품 링크, "링크에서 정보 가져오기", 사진과 쇼핑몰 이름, 목표 이름, 목표 금액, 이미 모은 금액, 목표 날짜가 있습니다.
  - 그 아래 진행액과 "$1,299 더 모으면 돼요", 저장, 저축 기록, 삭제 버튼, 오른쪽 위 지난 목표 이력이 있습니다.

`02-bought-it-ko.png`의 "링크에서 지금 가격 다시 읽기"는 수정 화면의 "링크에서 정보 가져오기"로 이미 할 수 있습니다. 다만 이름과 목표 금액을 새로 읽은 값으로 덮어씁니다. 시안에서 새로운 부분은 그 가격을 산 금액 기록에 쓰는 흐름입니다.

다시 만들기:

```sh

```
