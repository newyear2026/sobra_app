# 주기 마감 목표 팝업 — 한국어 시안

2026-11-09. 현재 구현된 홈 화면을 참고해 만든 제안 이미지이며, 팝업이나 주기별 목표 배정 기능을 구현한 결과는 아닙니다.

## 시안

- `01-existing-goal-ko.png`: 목표 있음. 남은 생활비 20,000원을 기존 ‘1억 모으기’ 목표에 반영하기 전 확인. 현재 10,000,000원 → 반영 후 10,020,000원. 전액 반영, 금액 변경, 나중에 선택.
- `02-no-goal-ko.png`: 목표 없음. ‘목표 만들고 모으기’ 또는 ‘나중에’. 목표를 정하기 전에 가짜 진행률이나 목표 이름을 만들지 않음.
- `03-goal-achieved-ko.png`: 목표 달성. 99,980,000원에서 마지막 20,000원을 기록하여 총 100,000,000원이 된 예시. 달성 팝업과 방 아래의 100% 완료 카드를 보여줍니다.
- `gallery.html`: 세 상태를 비교하는 로컬 갤러리.

## 제안 동작

1. 남은 생활비가 있는 주기를 마감한 뒤 팝업을 한 번 표시합니다. 기존 홈과 캐릭터 방은 배경으로 유지합니다.
2. 목표가 있다면 팝업에서 명시적으로 확인한 금액만 반영합니다. 금액 변경은 같은 팝업 안의 입력으로 연결합니다.
3. 목표가 없다면 목표 생성 화면으로 이동하고, 완료 후 해당 주기의 남은 금액이 선택된 확인 팝업으로 돌아옵니다. 목표 생성만으로 배정이 확정되지 않습니다.
4. ‘나중에’나 목표 생성 취소 시 배정하지 않습니다. 마감 기록은 유지하고, 홈에는 기존 목표 만들기 카드를 보여줍니다. 추후 마감 내역에서 다시 시작할 수 있게 연결하는 제안입니다.
5. 확정된 주기 배정은 한 번만 기록합니다. 동일 금액을 시작 금액과 주기 배정으로 이중 계산하거나 새 수입으로 생성하지 않습니다. 실제 은행 이체는 없습니다.
6. 목표 금액에 도달하면 축하 팝업을 한 번 표시하고 홈 카드를 달성 완료·100%로 바꿉니다. 확인하면 완료 카드는 유지됩니다. 새 목표 만들기는 선택 사항이며, 이전 달성 목표를 기록에 남기는 동작도 제안 범위입니다. 현재 앱에 달성 이력 보관까지 구현되었다는 뜻은 아닙니다.

‘남은 생활비’는 생활비 예산에서 해당 생활비 지출을 뺀 값이며, 은행 잔액을 확인한 값은 아닙니다. 10,020,000 / 100,000,000은 10.02%이며, 현재 앱의 정수 표시는 10%입니다.

내장 `image_gen` 도구로 각각 독립 생성했습니다. 정확한 프롬프트는 `01-existing-goal.prompt.txt`, `02-no-goal.prompt.txt`, `03-goal-achieved.prompt.txt`에 있습니다. 실제 화면 캡처가 아닌 디자인 검토용 이미지이므로 글꼴과 미세한 픽셀은 달라질 수 있습니다.
