# Sobrita 목표 설정 · 한국어 이미지 시안
2026-11-09. 내장 ImageGen으로 기존 스페인어 시안 다섯 장을 한국어로 편집했습니다.

- 기능 구성, 제품 사진, 캐릭터, 색상, 금액과 계산은 기존 시안을 유지했습니다.
- 통화는 MX$이며 원화로 환산하지 않았습니다.
- 상품 링크와 가격은 예시입니다. 자동 가격 추적이나 특정 쇼핑몰 지원을 보장하는 화면이 아닙니다.
- 목표 날짜는 선택이며, 저축 예정일은 자동이체가 아닙니다.
- 이미 모은 돈은 생활비와 별도로 분리해 둔 금액입니다.
- 목표에 더하기는 앱 안의 기록이며 실제 송금이 아닙니다.
- 앱 소스 및 실행 기능은 변경하지 않았습니다.

## 예시 계산
목표 MX$1,500, 시작 저축 MX$600 → 남은 MX$900, 3번에 MX$300씩.
지난 주기 잔액 MX$300 중 MX$150을 목표에 배정 → 총 MX$750, 진행률50%.
미배정 잔액은 MX$150이며, 목표까지 남은 금액은 MX$750입니다.
11월15일,11월30일,12월15일에 세 번 모은다면 이후 회당 MX$250입니다.

개별 PNG와 gallery.html을 열어 화면을 확인할 수 있습니다.
전체 편집 프롬프트는 prompts.json, 원본 및 생성 파일 정보는 manifest.json에 있습니다.
