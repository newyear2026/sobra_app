# 현재 캐릭터 홈을 유지하는 목표 카드 — 수정 시안

2026-11-09. 현재 홈 코드와 실제 Flutter 홈 렌더를 참고해 내장 image_gen으로 만든 배치 시안입니다. 실행 중인 앱의 스크린샷이나 구현 완료 화면이 아니며, 앱 소스는 변경하지 않았습니다. 금액은 예시입니다.

## 정확한 제안 위치

오늘 남은 돈 → 주기 예상 잔액 → 기존 캐릭터 방 → **작은 목표 카드 추가** → 기존 시즌/첫 지출 안내(해당 시) → 레벨·미션 → 주기 진행·현금·최근 내역.

- 기존 고정지출 안내가 있으면 현재처럼 방 앞에 유지합니다.
- 방의 정사각형 장면, 선택한 캐릭터·방·꾸미기 동작은 유지합니다.
- 목표 카드는 방 바로 뒤에 12dp 간격으로 추가하는 제안입니다. 높이는 약 64–72dp, 상품 사진은 약 36–40dp입니다.
- 카드에는 목표 이름, 모은 금액/목표 금액, 진행률, 상세 화면 진입 화살표만 둡니다.
- 목표가 없으면 같은 위치에 높이 약 48–56dp의 작은 '갖고 싶은 것을 목표로 정해요 +' 진입 줄을 제안합니다.
- 하단 메뉴는 홈 / 내역 / + / 예산 / 내 정보, 현재의 5개 슬롯과 72dp 높이를 유지합니다. 목표 전용 탭을 추가하지 않습니다.
- 작은 화면이나 추가 안내가 있는 상태에서는 목표 카드가 첫 화면 아래에 위치하므로 조금 스크롤해야 합니다. 이를 맞추려고 방을 줄이지 않습니다.
- 기존 docs/savings-goal.md의 방 위 배치는 이전의 미구현 제안입니다. 이번 수정안은 사용자가 강조한 캐릭터 영역을 유지하기 위해 방 아래에 배치합니다.
