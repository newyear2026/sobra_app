# Sobrita 동전 저축 로딩 모션 시안

- `coin-loading-preview.gif`: 채팅에서 볼 수 있는 반복 미리보기.
- `coin-loading-preview.mp4`: 426×922 영상, 무음, 3.5초.
- 동작 2.5초 + 마지막 웃는 자세 1초 유지 후 미리보기 반복.
- 동전 들어 올리기 → 놓기 → 저금통 안으로 떨어지기 → 반짝임 → 눈을 감고 끄덕이기 → 웃는 자세 유지.
- 내장 이미지 생성 도구로 동작 원화와 배경을 제작하고, FFmpeg로 생성된 12개 프레임을 조립했습니다.
- 원화·배경 프롬프트: `motion.json`, `background-prompt.txt`.
- 재생성: `python3 build_preview.py` (FFmpeg 필요).
- 검토용 시안이며 앱 코드는 변경하지 않았습니다. 실제 적용 시 로딩이 끝나면 모션 종료를 기다리지 않고 다음 화면으로 전환합니다.
- 최종 앱 에셋 제작 시 저금통 외곽과 캐릭터 윤곽의 미세한 프레임 차이를 추가 정리할 수 있습니다.
