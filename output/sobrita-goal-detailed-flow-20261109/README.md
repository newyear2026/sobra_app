# Sobrita · 제품 목표 상세 흐름
작성일: 2026-11-09 (America/Mexico_City). 내장 ImageGen으로 만든 UI 시안입니다. 앱 기능 구현은 포함하지 않습니다.

## 사용 흐름
1. 상품 확인: 상품 링크를 붙여 넣거나 다른 앱에서 공유합니다. 가져온 사진·이름·가격을 확인하고 필요한 항목만 수정합니다. 사진과 링크 없이도 목표를 만들 수 있습니다.
2. 저축 계획: 이미 생활비 밖에 따로 둔 돈과 선택 기한을 입력합니다. 기한을 정하면 다음 저축 예정일을 보여주고 회당 금액을 제안합니다. 자동이체나 급여일을 의미하지 않습니다.
3. 홈: 작은 썸네일·이름·모은 금액·진행 막대만 유지합니다. 자세한 정보는 카드를 눌러 확인합니다.
4. 모으기: 돈의 출처를 먼저 구분하고, 배정할 금액과 반영 후 결과를 확인합니다. 이미지의 예시는 지난 주기 잔액에서 배정하는 경우입니다.
5. 목표 상세: 진행률, 남은 계획, 날짜와 출처가 있는 내역을 보여줍니다. 잘못된 기록 수정과 목표 자금 해제는 구분합니다.

## 이미지에서 이어지는 예시
- 목표 제품: Mis tenis, 목표 금액 MX$1,500.
- 11월 9일 생성 시: 이미 모은 MX$600, 진행률 40%, 부족한 금액 MX$900.
- 선택한 목표일: 2026-12-15. 저축 예정일은 11/15, 11/30, 12/15의 세 번. 제안액은 회당 MX$300.
- 같은 날 지난 주기의 잔액 MX$300 중 MX$150을 추가로 목표에 배정.
- 배정 후: MX$750 / MX$1,500, 50%. 지난 주기 잔액 중 미배정액은 MX$150.
- 추가 저축은 예정일 이전에 한 별도 배정이므로 미래 세 번은 유지. 남은 MX$750을 세 번에 나누면 회당 MX$250.

## 저축 추가에서 돈의 출처
- 이미 생활비와 분리한 저축: 목표 배정만 늘리고 생활비와 지갑을 다시 변경하지 않습니다.
- 현재 생활비에서 따로 떼기: 목표 배정은 늘리고 현재 사용 가능 예산은 같은 금액만큼 줄입니다. 지갑 총액은 바뀌지 않습니다.
- 지난 주기의 남은 돈: 현재 예산에 다시 포함하지 않았으며 아직 보유 중인 금액인지 확인합니다.
- 새로운 수입: 기존 수입 기록의 저축 배정 흐름으로 연결합니다. 이미 가진 돈을 새 수입으로 기록하지 않습니다.
- 시작 금액이나 이전 배정에 포함된 돈을 다시 더하지 않도록 원본 기록과 목표 기여를 연결해야 합니다.

## 수정·해제·달성
- 기록 수정: 해당 금액과 그로부터 계산한 진행률/계획을 갱신합니다.
- Quitar dinero: 목표 배정을 해제하는 행동입니다. 생활비로 돌리는 경우에만 사용 가능 예산을 늘립니다. 실제 구매 지출과 중복 차감하지 않습니다.
- 목표 금액을 수정해도 모은 금액은 유지하고 진행률과 남은 계획만 다시 계산합니다.
- 기한 없이도 목표를 생성할 수 있습니다. 이때 회당 목표액을 강제로 제시하지 않습니다.
- 예정일이 지난 경우 남은 날짜를 다시 선택하게 하고, 0회로 나누거나 음수 저축 계획을 표시하지 않습니다.
- 목표 도달 시 '목표 금액 달성'을 표시합니다. 상품 가격을 확인하는 것은 별도이며, 자동 구매하거나 실제 잔액을 확인했다고 표현하지 않습니다.

## 이미지 출처
신규 생성: 상품 확인, 저축 계획, 목표 상세.
이전 선택안 재사용: 작은 홈 카드, 주기 잔액 계산 및 배정 미리보기.
상품과 링크는 예시입니다. 특정 쇼핑몰의 링크 가져오기가 검증된 상태는 아닙니다.
전체 신규 이미지 프롬프트는 prompts.json에 있습니다.
