# Sobrita · 제품 사진 저축 목표 UI 시안

제작일: 2026-11-06. 내장 ImageGen으로 생성한 앱 화면 제안입니다. 실제 기능 구현이나 앱 코드 변경은 포함하지 않습니다.

## 흐름

1. 목표 만들기: 제품 사진을 직접 추가하고 이름, 목표 가격, 이미 따로 모은 금액을 입력합니다. 날짜는 선택입니다.
2. 홈에서 목표 확인: 오늘 쓸 수 있는 예산과 목표 진행액을 분리하고, 제품 사진·진행률·남은 금액을 보여 줍니다.
3. 목표에 배정: 주기 마감 후 남은 돈 중 사용자가 고른 금액만 목표에 배정합니다. 확인 전 진행률을 미리 보여 줍니다.

예시: Mis tenis / 목표 MX$1,500 / 기존 MX$600(40%) / 추가 MX$150 / 결과 MX$750(50%), 남은 금액 MX$750.

## 화면 원칙

- 활성 목표 하나, 사진은 사용자가 선택합니다.
- 저축 진행률은 단순 지출 기록만으로 증가하지 않습니다.
- 예산 잔여액을 자동으로 목표에 넣지 않으며, 배정은 사용자가 확인합니다.
- 앱이 돈을 이체하거나 새 수입을 만들지 않습니다.
- 상품 검색, 구매, 자동 가격 추적은 포함하지 않습니다.
- 기존 Sobrita의 크림/청록색, 픽셀 글꼴, 각진 테두리, 캐릭터 스타일을 참고했습니다.
- 참고한 design/savings-goal 화면은 기존 기능 제안 시안이며 출시 화면으로 단정하지 않습니다.

전체 생성 프롬프트: prompts.json

## 홈 카드 축소 수정안 (v2)

사용자 피드백: 제품 사진과 목표가 홈 화면에서 너무 많은 공간을 차지함.

- 홈 목표 카드는 약 92px 높이의 가로형 요약으로 축소합니다.
- 제품 사진은 약 56px 정사각형 썸네일로 보여줍니다.
- 목표 이름, 모은 금액/목표 금액, 얇은 진행 막대, 상세 진입 화살표만 남깁니다.
- 큰 제품 사진, 수정, 남은 금액, 돈 배정은 목표 상세 화면에서 보여줍니다.
- 홈의 오늘 예산과 캐릭터 방을 우선합니다.

### 이미지 입력 제안

목표 생성/수정에서 `Añadir imagen (opcional)`을 누릅니다.

1. `Elegir de la galería` — 갤러리의 상품 사진 또는 쇼핑몰 화면 캡처를 선택합니다. 기본 경로입니다.
2. `Tomar foto` — 직접 촬영합니다. 선택 사항입니다.
3. `Ahora no` — 이미지 없이 만들며, 기존 카테고리 아이콘을 보여줍니다.

사진을 선택하면 정사각형 썸네일에 맞춰 표시 위치를 조절하도록 제안합니다. 현재 시안의 운동화 사진은 사용자가 선택한 이미지를 가정한 생성 예시입니다. 상품명만으로 자동 검색하거나 상품 링크에서 사진을 가져오는 기능을 의미하지 않습니다. 아직 이 입력 기능은 구현하지 않았습니다.
